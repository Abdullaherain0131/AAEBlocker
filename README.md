## 🌟 What makes AAEBlocker different?
Standard ad blockers rely on static text lists. When an advertiser changes their code, the blocker breaks until a human writes a new rule.  
**AAEBlocker is fully autonomous.** It uses a massive, self-updating Neural Network to "see" and "understand" web pages. It kills ads, trackers, and paywalls at the speed of light using hardware-accelerated AI.

## 🚀 The V11 Arsenal (Key Features)

### ⚡ 1. Hardware Accelerated AI (WASM & TFLite)
- **PC (WebAssembly):** The massive 260MB JSON brain is executed via highly optimized C++ WebAssembly (WASM). Millions of matrix multiplications are processed in under **1-2 milliseconds**, ensuring zero page load delay.
- **Mobile (TFLite):** For Android (Kiwi Browser), the AI automatically switches to a lightweight 49MB **TensorFlow Lite** model, maximizing battery life and minimizing RAM usage.

### 🧠 2. Federated Learning (The Hive-Mind)
<div align="center"><img src="https://media.giphy.com/media/13HgwGsXF0aiGY/giphy.gif" width="400" style="border-radius: 10px; margin: 10px 0;" alt="Neural Network Nodes"></div>

- **Delta/Gradient Sync:** When you manually block an undetected ad, AAEBlocker calculates a mathematical "Gradient" (just 4 KB) using local backpropagation and shares it anonymously with the network.
- **Wi-Fi Only Mode:** Gradients are stored locally and only uploaded when a Wi-Fi connection is detected (`navigator.connection`), saving your cellular data.
- **Data Poisoning Defense:** The network uses a Consensus Algorithm and a Reputation System to ignore fake reports. If one user learns to block a new ad, the entire world learns it by morning.

### 🔪 3. DOM Surgeon (Smart Anti-Adblock & Paywall Cracker)
<div align="center"><img src="https://media.giphy.com/media/YQitE4YNQBroM/giphy.gif" width="400" style="border-radius: 10px; margin: 10px 0;" alt="Cyber Surgery"></div>

Tired of "Please disable your ad blocker" popups locking your screen?
- The **DOM Surgeon** uses a MutationObserver to detect background blurring (`backdrop-filter`) and massive `z-index` overlays.
- It automatically annihilates these overlays and forces the page to become scrollable again (`overflow: auto !important`). You'll never be locked out of a website again.

### 🎬 4. Auto Video Ad-Skipper
Automatically detects in-video ads on YouTube and similar platforms.
- Instantly **mutes** the audio.
- Speeds up the playback to **16x** (browser limit).
- Automatically clicks the **"Skip Ad"** button if it appears!

### 🎭 5. Cyber Terminal (Hacker CLI)
The extension panel houses a true Hacker Terminal. Take full control:
- `/ogren` : Element selector to teach the AI on mobile/touch devices.
- `/kalkan` : Force-break the site's background lock.
- `/ghost` : Disguise your browser as Googlebot to bypass paywalls.
- `/imha` : Instantly detonates all currently known ad codes.
- `/nojs` : Freezes and destroys all JavaScript on the active page.

## 📥 Installation (Serverless Architecture)
AAEBlocker downloads its massive AI models directly from GitHub Releases, making it 100% free and independent.

### PC (Desktop) - Firefox & Zen Browser
1. Download `AAEBlocker.xpi` from the **Releases** section.
2. Open Firefox/Zen Browser, go to `about:addons` (or `about:debugging`), and drag & drop the file to install it.
3. *Note: The extension will automatically download the 260MB WASM model upon first run.*

### Mobile (Android) - Kiwi Browser
1. Download **Kiwi Browser** from the Play Store.
2. Download the `AAEBlocker_Chromium.zip` file to your phone.
3. Go to the Extensions tab in Kiwi Browser and enable **Developer Mode**.
4. Tap `+(from .zip)`, select the zip file, and complete the installation.
5. *Note: The extension will automatically download the lightweight 49MB TFLite model.*
