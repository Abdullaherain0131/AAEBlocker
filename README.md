## 🌟 Why AAEBlocker?
Standard ad blockers rely on static filter lists and need constant updates. **AAEBlocker is different.** 
It uses a **Linear Neural Network (Perceptron AI)** that runs entirely inside your browser without needing any external API or server. 
It analyzes every element it sees, learns, and eradicates ads before you even notice them.

## 🚀 Key Features

### 🧠 1. Local AI Core (In-Browser Neural Net)
- **Gradient Descent Learning:** Right-click on any ad and select "This is an Ad" to train the AI. It learns from its mistakes and builds its own brain inside `chrome.storage`.
- **Zero-Delay Observer:** Detects late-loading ads within milliseconds and blinds them instantly (if the AI score is > 75%).
- **Privacy-First:** Sends absolutely zero data to external servers (No OpenAI etc.). Everything happens locally on your device.

### ☁️ 2. "Hive Mind" (Real-Time Cloud Sync)
When you train the AI, the mathematical weights are pushed to a secure **Firebase Cloud Database**. When a new user installs AAEBlocker, it pulls everyone's weights, averages them out, and merges them with the local brain. **If one user defeats an ad, millions of users instantly learn how to defeat it too!**

### 🎬 3. Auto Video Ad-Skipper
Automatically detects in-video ads on YouTube and similar platforms.
- Instantly **mutes** the audio.
- Speeds up the playback to **16x** (browser limit).
- Automatically clicks the **"Skip Ad"** button if it appears!

### 🎭 4. Anti-Anti-Adblock & Ghost Mode
Tired of "Please disable your ad blocker" popups on news sites?
- Type `/kalkan` (Shield) in the terminal to break the site's background lock.
- Type `/ghost` in the terminal to disguise your browser as Googlebot, allowing you to bypass paywalls and read premium content.

## 💻 Cyber Terminal (Command Line Interface)
The extension panel houses a true Hacker Terminal. Take full control:
- `/ogren` : Element selector to teach the AI on mobile/touch devices.
- `/imha` : Instantly detonates all currently known ad codes.
- `/nojs` : Freezes and destroys all JavaScript on the active page.
- `/speed` : Activates the media acceleration engine.

## 📥 Installation

### PC (Desktop) - Firefox & Zen Browser
1. Download `AAEBlocker.xpi` from the **Releases** section.
2. Open Firefox/Zen Browser, go to `about:addons` (or `about:debugging`), and drag & drop the file to install it.

### Mobile (Android) - Kiwi Browser
1. Download **Kiwi Browser** from the Play Store.
2. Download the `AAEBlocker_Chromium.zip` file to your phone.
3. Go to the Extensions tab in Kiwi Browser and enable **Developer Mode**.
4. Tap `+(from .zip)`, select the zip file, and complete the installation.
